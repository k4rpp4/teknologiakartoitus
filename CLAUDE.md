# Teknologia arjessani – TOTA

Static single-page site (`index.html` + `assets/`) for the TOTA project ("Teknologia, Osallisuus, Toimintakyky, Asiakaslähtöisyys"). No build step, no framework — just edit `index.html` and the image files in `assets/` directly.

## ⚠️ No longer deployed from this repo

As of 2026-09-21, this tool is served from **`k4rpp4/totahanke`**'s `teknologiakartoitus/` subfolder at https://totahanke.dev.roboai.fi/teknologiakartoitus/ — one shared Coolify resource/domain now serves the TOTA hub and all of its tools as subpaths, instead of each tool having its own Coolify resource/domain. The standalone `teknologiakartoitus.dev.roboai.fi` domain and its dedicated Coolify resource have been deleted.

This repo (`~/projects/teknologiakartoitus`) still exists on GitHub but is no longer the deployed source — make future edits in `k4rpp4/totahanke`'s `teknologiakartoitus/` subfolder instead, and treat this repo's content as historical/superseded.
